# 语境岛 · 公开原型

这是「语境岛」的公开交互原型，用来展示产品界面、实时生成词卡、句子结构标注与发音交互。

在线体验：<https://mollyhan-ai.github.io/context-island-demo/>

## 当前范围

- 可以浏览页面并切换学习领域。
- 可以查看 `exposure` 的预置样卡与句子结构。
- 可以搜索词库中的英文单词，并由 Qwen 实时生成带中文释义的情境词卡。
- 可以体验单词发音、整句朗读和义项展开。

后端使用 Render 免费实例。长时间无人访问后，第一次搜索可能需要等待约 50 秒唤醒服务；随后通常会在数秒内完成。

完整项目代码和开发文档：[语境岛公开仓库](https://github.com/mollyhan-ai/context-island)。
